STUDENT REPORT CARD GENERATOR
==============================

FILES
-----
app.py       Main Python program and website.
students.json  Created automatically after the first student is saved.
Project_Report.docx  Project report.

REQUIREMENT
-----------
Python 3 installed on your computer. No extra Python packages are required.

HOW TO RUN
----------
1. Extract this ZIP file into a folder.
2. Open that folder.
3. Double-click app.py OR open Command Prompt in this folder and type:
       python app.py
   If that does not work on Windows, try:
       py app.py
4. Keep the black terminal/Command Prompt window open.
5. Open Chrome or Edge and visit:
       http://127.0.0.1:8000
6. Fill the student form and click Generate Report Card.
7. Use Print / Save as PDF to save a report card.
8. Stop the website by returning to the terminal and pressing Ctrl+C.

IMPORTANT
---------
The website address works on the same computer while app.py is running.
It is not a public internet link. A public link requires hosting the Python
program on an internet hosting service.

GRADING RULES
-------------
A+ : 90% and above
A  : 80% to below 90%
B  : 70% to below 80%
C  : 60% to below 70%
D  : 50% to below 60%
E  : 33% to below 50%
F / Fail: below 33 in any one subject

The project uses five subjects, each out of 100 marks.
